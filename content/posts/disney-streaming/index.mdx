## Working for the House of Mouse

I'm thrilled to announce that I've started a new position as a Senior Software Engineer at Disney Streaming! It's an exciting opportunity for me to learn a new tech stack and grow as a developer while supporting the ecosystem that delivers our favorite shows and movies. Shoutout to [Robert Romito](https://www.linkedin.com/in/robertromito) for putting in a good word and being awesome throughout onboarding, twice!

As for the team I'm departing, it has been a privilege to work at the [American Red Cross](https://www.redcross.org/about-us/careers.html) with such wonderful people while supporting a noble cause. If anyone in my network has the interest and the aptitude to work on a large enterprise web CMS, ARC is a fantastic place to do it. Thank you for the opportunity.

## A New Vue On Life

As part of my interview prep for the new position, I took the initiative to rewrite this site in the [Vue.js](https://vuejs.org/) framework. It's been a great way to acclimate myself with the framework I'll be using to build internal tools for Disney while keeping things fresh here. So far I find the framework to have the best qualities of React and Angular while remaining independent of a large firm. I love the Single File Component architecture. It somehow feels familiar yet more modern than JavaScript libraries I've used before.
